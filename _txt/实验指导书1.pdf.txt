实验1 VSCode C++ 开发环境构建
 
1.1 远程软件开发环境搭建
 
1.1.1 实验⽬的
 
了解如何使⽤ VSCode 远程连接 Linux 服务器（以 Ubuntu 为例），并在远程环境中搭建 C++ 开发环境。
1.1.2 实验内容与要求
 
要求
 
掌握 VSCode 远程连接 Linux 的⽅法。
在 VSCode 远程环境中搭建 C++ 开发环境。
环境
 
1. Windows 桌⾯终端⼀台。
2. Ubuntu 服务器⼀台。
内容
 
⼀、在 Windows 上安装 VSCode
 
1. 前往 Visual Studio Code 官⽹：https://code.visualstudio.com/。
2. 下载适⽤于你操作系统的版本（Windows），双击下载的安装程序（.exe ⽂件）。
3. 然后按照安装向导进⾏安装。
⼆、配置 Ubuntu 服务器（远程登录和C++编译环境）
 
1. 更新软件源：sudo apt update 。
2. 安装 ssh 服务：sudo apt install openssh-server 。
3. 确保在 Windows 上可以通过 ssh 登录到 Ubuntu。
4. 安装 gcc ⼯具链：sudo apt install build-essential gdb 。

=== PAGE 2 ===
5. 确认 gcc 安装成功：gcc -v 。
三、安装 VSCode 远程连接插件
 
1. 打开VSCode。
2. 按下快捷键 <Ctrl-Shift-x>  或点击侧边栏的 "Extensions" 搜索插件。
3. 在搜索框中输⼊ "Remote-SSH" 并安装该插件。
4. 安装完成后，重新启动VSCode。

=== PAGE 3 ===
四、VSCode 通过 SSH 远程连接 Ubuntu 服务器
 
1. 打开VSCode，点击左下⻆的 "Open a Remote Window" 按钮。
2. 在弹出的下拉菜单中选择 "Connect to Host..." 。
3. 在输⼊框中输⼊远程计算机（Ubuntu 服务器）的 ⽤户名@IP地址（如：usr@192.168.221.131 ）。
4. ⼀路回⻋直到提示输⼊密码。
5. 等待连接成功后，就能连接远程计算机的⽂件系统。

=== PAGE 4 ===

1. 打开VSCode。
2. 按下快捷键 <Ctrl-Shift-x>  或点击侧边栏的 "Extensions" 搜索插件。
3. 搜索并安装 C/C++ 相关插件。
