白名单逻辑：只备份勾选的类型。勾选“all”或全选具体类型（默认）= 不限制类型；全部取消也按“不限制”处理（否则备份必为空）。
–
区间含义：修改时间 ≥ 起始 且 ≤ 结束，留空一侧表示不限；勾选后才生效（等同 CLI --newer-than / --older-than）。
参考界面里的“创建时间”本系统未采集，故只提供修改时间筛选。
–
留空或 0 表示不限；仅对普通文件生效（等同 --min-size / --max-size）。
排除用户（属主名 ownerNames）
按属主名排除等同 CLI --owner，仅在支持属主解析的平台（POSIX）生效； Windows 上本页会置灰，避免“设了不生效”。用户组（gid）过滤后端暂未提供，故本页只做“用户”。
名称白名单 nameGlobs（只备份匹配的文件名）
名称黑名单 nameRejects（排除匹配的文件名）
glob 语法：* ? [abc]，只匹配文件名本身（等同 --name / --no-name）。 参考界面用正则，本系统与命令行统一用 glob。
排除目录 / 路径 excludePaths（匹配相对路径的 glob）
包含路径 includePaths（只备份匹配的路径，父目录自动放行）
路径相对“数据路径”（/ 分隔）；用“添加目录…”选择时会自动换算成相对路径。
遍历选项（深度 / 链接 / 跨设备）
提示：所有条件都是“白名单/区间”语义，AND 组合；不填即不限制。
